# DevOps-Mini-Project-Soham
Collection of DevOps mini projects covering Linux automation, Git workflows, CI/CD, Docker, and DevOps practices.

This repository contains five DevOps mini projects demonstrating automation, version control, CI/CD, and containerization concepts.

## Projects

### 1. Linux Sysadmin Automation Kit

**Objective:** Automate system monitoring using Bash scripting.

**Technologies:** Bash, Git, GitHub

**Features:**
- Disk usage monitoring
- System information reporting
- Automated log generation

---

### 2. Git Workflow Simulator

**Objective:** Simulate a professional Git workflow.

**Technologies:** Git, GitHub

**Features:**
- Feature branches
- Branch merging
- Release tagging
- Contribution guidelines

---

### 3. Python CI Pipeline

**Objective:** Implement Continuous Integration using GitHub Actions.

**Technologies:** Python, Pytest, Flake8, GitHub Actions

**Features:**
- Automated testing
- Code linting
- CI workflow execution

---

### 4. Lint Gate Demo

**Objective:** Implement a fast-fail quality gate to prevent improperly formatted code from being committed or pushed.

**Technologies:** Git, GitHub, Node.js, Prettier, Husky, GitHub Actions

**Features:**
Automated code formatting validation
Husky pre-commit hooks
GitHub Actions CI workflow
Fast-fail quality gate implementation
Consistent code quality enforcement

---

### 5. Dockerized To-Do API

**Objective:** Containerize a Flask REST API using Docker.

**Technologies:** Python, Flask, Docker

**Features:**
- REST API endpoints
- Docker image creation
- Containerized deployment
